# 个人网站

单文件静态站点。`index.html` 里内联了全部 CSS 与 JavaScript，不依赖任何外部资源，双击即可在浏览器打开，断网也能正常显示。

## 文件

```
index.html                     整个网站
assets/video/hero-720.mp4      首屏背景视频
assets/video/hero-poster.jpg   首屏海报图（视频加载前显示）
```

`assets` 必须和 `index.html` 放在一起。缺少视频时首屏会降级成一块带说明的占位区，页面其余部分正常。

## 改内容

正文内容集中在 `index.html` 底部的两个数组里，改这两处就够了：

- `ARTICLES` —— 文章卡片与阅读层（标题、导语、摘录、链接）
- `CARES` —— 「我更在意的几件事」四条主张

视觉参数集中在 `<style>` 顶部的 `:root` 变量里（颜色、间距、圆角、字体栈）。

## 现状

页面内容已全部填实，没有占位符。文章卡片点开是导读层（写作缘由 + 摘录 + 跳转公众号读原文），正文放在公众号。

若想把正文搬进网站，在 `ARTICLES` 的每篇里加一个正文字段，再改阅读层的渲染即可。
